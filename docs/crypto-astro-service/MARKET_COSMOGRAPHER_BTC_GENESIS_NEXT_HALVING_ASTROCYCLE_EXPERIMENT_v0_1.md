# Market Cosmographer · BTC Genesis → Next Halving Astrocycle Experiment v0.1

## Decision

This contour starts a second, independent research experiment without changing the accepted 30-day market-only utility pilot.

It separates four truths:

1. **Protocol time:** exact block heights and immutable boundary blocks.
2. **Calendar estimates:** derived from observed or target block intervals, never consensus triggers.
3. **Market time:** begins only where accepted price/volume observations exist; no Genesis price is invented.
4. **Astrocycle context:** research-only until deterministic ephemeris, aspect, orb and validation contracts pass.

## What is learned from Merriman's public method

The missing layer is not merely a list of aspects. A complete research contour requires:

`MARKET CYCLE DUE → CYCLE PHASE → GEOCOSMIC SIGNATURE → ORB → CLUSTER → REVERSAL WINDOW → TECHNICAL CONFIRMATION → REVIEW`

The experiment does not copy proprietary MMA scores, recommendations or subscriber signals. It uses only publicly described methodological classes as a comparison checklist.

## Phase 0 — implemented here

A dynamic internal workflow reads the current Bitcoin tip, binds its exact block hash and timestamp, and computes:

- Genesis-to-tip block delta;
- current halving-epoch progress from block `840000`;
- blocks remaining to canonical next-halving height `1050000`;
- target-time deltas using `600` seconds per block;
- exact days since Genesis and since the current epoch boundary;
- a machine-readable Astromodule readiness decision.

The next halving is defined by height `1050000`. Any calendar timestamp is an estimate.

## Phase 1 — next gate

The Astromodule must produce byte-deterministic, source-pinned ephemeris states for:

- Genesis block timestamp;
- historical halving boundary block timestamps;
- dynamic current-tip block timestamp;
- a projected next-halving date band, explicitly non-canonical.

Before any run, the exact ephemeris implementation, data files, body list, frame, time conversion, aspect families and orbs must be frozen.

## Phase 2 — later historical test

Market cycle labels must be generated independently of astro data. The pre-registered astro signature clusters are then tested for overlap with independently labelled cycle turns against circular-shift and matched-window controls.

No result may become a product field without non-overlapping replication, multiple-testing control and a separate product-language review.

## Boundary

- Internal research only.
- No change to the daily utility pilot.
- No public surface or public Snapshot change.
- No A/E scoring activation.
- No forecast, probability, trading signal, price target or recommendation.
- No claim that halving or an astrocycle causes BTC price movement.
